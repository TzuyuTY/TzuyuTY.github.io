Project Overview

Palm Racer is a real-time hand-gesture-controlled robotic vehicle developed during UC San Diego's Summer Internship Preparatory Program (SIPP). The system uses computer vision to recognize hand gestures and translate them into movement commands for the vehicle.

How It Works

Camera → OpenCV / MediaPipe → Hand Gesture Detection → Python → Serial Communication → Metro M0 Express → L298N Motor Driver → DC Motors

Hardware

  • Metro M0 Express microcontroller
  • L298N motor driver
  • DC motors
  • Battery pack
  • Custom-built chassis
  • Jumper wires and soldered connections

Software

  • Python
  • OpenCV
  • MediaPipe
  • CircuitPython

My Contribution

I developed and integrated the hand-gesture recognition system, connected the software to the vehicle's microcontroller, and built and wired the physical prototype.

Engineering Process

The project involved integrating computer vision, serial communication, embedded programming, and electronic hardware into a single working system. I tested the vehicle's movement commands, debugged hardware and software integration issues, and iterated on the physical prototype.

Final Result

The final prototype could interpret hand gestures and translate them into forward, backward, left, right, and stop commands in real time.
